# موقع المترجم: نسخة WordPress المحلية

موقع WordPress كامل بلغتين (إيطالي + عربي RTL)، شغّال على جهازك عن طريق Docker.

## أول مرة (تركيب من الصفر)

بتحتاج Docker Desktop و Git Bash (أو أي terminal فيه `sh`).

```bash
cp .env.example .env      # افتح .env وحط كلمات سر جديدة
docker compose up -d      # بينزّل ويشغّل WordPress + قاعدة البيانات + Mailpit
sh tools/setup.sh         # بيركّب WordPress واللغتين والإضافات والثيم وبيبني الصفحات
```

اسم المستخدم وكلمة السر للوحة التحكم هم اللي حطيتهم بملف `.env` (`WP_ADMIN_USER` و `WP_ADMIN_PASSWORD`).

## التشغيل والإيقاف

افتح **Docker Desktop** أولاً، وبعدين من داخل هاد المجلد:

```bash
docker compose up -d      # تشغيل
docker compose stop       # إيقاف (المحتوى بيضل محفوظ)
```

| الرابط | شو هو |
|---|---|
| http://localhost:8088 | الموقع بالإيطالي |
| http://localhost:8088/ar/ | الموقع بالعربي |
| http://localhost:8088/wp-admin | لوحة التحكم (اسم المستخدم وكلمة السر من ملف `.env`) |
| http://localhost:8025 | الإيميلات اللي بتوصل من نموذج التواصل (مع المرفقات) |

## وين العميل بيعدّل

- **النصوص والصور:** الصفحات › اختار الصفحة › اكبس على أي نص أو صورة وعدّل.
  - لتغيير الصورة الشخصية: اكبس عالصورة › استبدال.
- **الشريط الأخضر بآخر كل صفحة ("عندك وثيقة للترجمة؟"):** هاد "نمط متزامن" (Synced pattern). بيتعدّل مرة وحدة، والتعديل بيطلع بكل الصفحات.
- **الختم الدائري بألوان علم إيطاليا (فوق الصورة بالرئيسية):** بلوك "HTML مخصص". بينحذف أو بيتعدّل نصه من المحرر.
- **"متاح لمهام جديدة" وشارات الاعتمادات (CTU، DITALS...):** فقرات عادية بالصفحة الرئيسية، بتتعدّل متل أي نص.
- **القوائم:** المظهر › القوائم. في قائمة لكل لغة.
- **رقم الهاتف والواتساب والإيميل والرقم الضريبي:** المظهر › تخصيص › Contatti e WhatsApp.
- **اللوغو:** المظهر › تخصيص › هوية الموقع.
- **نصوص الهيدر والفوتر بالعربي:** اللغات › ترجمة النصوص.
- **عنوان كل صفحة ووصفها بجوجل:** أسفل محرر الصفحة › Rank Math.
- **النموذج:** Contact › Contact Forms. في نموذج لكل لغة.

## ملفات المشروع

- `theme/`: الثيم المخصص (Traduttore). بعد أي تعديل على `theme/assets/wp.css` شغّل `node tools/build-css.js`.
- `seed/`: السكريبت اللي بيبني الصفحات. **تنبيه:** إذا شغّلته من جديد بيمسح الصفحات وبيرجع يبنيها، يعني بتروح أي تعديلات عملتها من لوحة التحكم.
- `tools/setup.sh`: تركيب كامل من الصفر.
- `mu-plugins/local-mail.php`: للنسخة المحلية بس، بيحوّل الإيميلات لـ Mailpit. **ما بينرفع عالسيرفر الحقيقي.**

## قبل ما نرفع عالاستضافة الحقيقية

1. نبدّل الاسم والنصوص والصور الحقيقية.
2. نركّب WP Mail SMTP مع إيميل الاستضافة، حتى توصل رسائل النموذج فعلياً.
3. نضيف سياسة الخصوصية والكوكيز (Complianz أو Iubenda).
4. نحمّل الخطوط على السيرفر نفسه بدل Google Fonts (أأمن من ناحية GDPR).
5. ننقل الموقع بإضافة نقل (مثلاً All-in-One WP Migration)، ونعمل كلمات سر جديدة.
